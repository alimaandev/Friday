## 🎯 Tu Centro de Comando de IA para el Escritorio

**Friday** es una IA de código abierto de nivel JARVIS que vive en tu escritorio. Háblale, hazle gestos o escribe — ve tu pantalla, controla tu computadora, ejecuta automatizaciones, visualiza datos en 3D y responde con personalidad. Todo se ejecuta localmente. Tu clave de API, tu LLM, tus reglas.

> El orbe 3D reacciona a tu voz. El panel de Inteligencia transmite 10 fuentes de datos en vivo. El Holodeck renderiza tus métricas como barras 3D animadas. El modo Zen lo convierte todo en un orbe monocromo + chat. Y todo comienza con un solo comando.

```bash
npm run friday        # → arranca el servidor API + el frontend juntos (Windows)
# o
docker compose up -d  # → Frontend: http://localhost:5173 · Backend: http://localhost:8080
```

## 🤔 ¿Por qué Friday?

**Los asistentes en la nube son convenientes — y ese es el problema.** Viven detrás de un sitio web, son dueños de tu historial de conversaciones, suben tu pantalla a pedido a un proveedor que no elegiste y cobran una suscripción por funciones que podrías ejecutar tú mismo.

**Friday es la alternativa que te devuelve el control:**

- 🖥️ **Primero el escritorio** — se ejecuta donde trabajas. Sin pestañas, sin momentos de "lo siento, eso solo puedo hacerlo en la nube".
- 🔑 **Trae tu propio LLM** — conecta OpenRouter, OpenAI, Ollama o cualquier endpoint compatible con OpenAI. Tu clave, tu proveedor, tu facturación, tus reglas. No existen servidores de Friday — no hay nada por lo que cobrarte.
- 🔒 **Local por diseño** — la memoria, las definiciones de automatizaciones y los tokens de Google viven en una carpeta `memory_store/` en *tu* máquina, no en la base de datos de otra persona. Consulta [Privacidad y Seguridad](#-privacidad-y-seguridad).
- 🎭 **Una personalidad, no un chatbot** — tres personajes de voz, conversación ambiental y un orbe 3D que reacciona a ti. *Se siente* como un compañero, porque ese es el punto.
- 🧩 **Extensible** — plugins, herramientas personalizadas y un planificador que descompone grandes metas en pasos ejecutados. Si puedes escribirlo como script, Friday puede ejecutarlo.

> **La propuesta en una frase:** Friday es un asistente de IA de nivel JARVIS que realmente posees — gratuito, de código abierto (MIT) y ejecutándose por completo en tu hardware.

## ⚡ Inicio Rápido

### 🚀 Comando único (recomendado)

```bash
git clone https://github.com/alimaandev/Friday.git
cd Friday
cp config/providers.toml.example config/providers.toml
# Edita config/providers.toml — pega tu clave de API de OpenRouter (u otra)
npm run friday        # arranca el servidor API + el frontend, abre tu navegador
```

### 🐳 Docker

```bash
git clone https://github.com/alimaandev/Friday.git
cd Friday
cp config/providers.toml.example config/providers.toml
# Edita config/providers.toml — pega tu clave de API
docker compose up -d
```

### 🔧 Configuración manual

```bash
git clone https://github.com/alimaandev/Friday.git
cd Friday
pip install -r requirements.txt
cp config/providers.toml.example config/providers.toml
# Edita config/providers.toml — pega tu clave de API
cd desktop && python api_server.py &
cd .. && npm install && npm run dev
```

## 🔒 Privacidad y Seguridad

Friday está diseñado para que *tus datos sigan siendo tuyos*. Esto es exactamente lo que ocurre con ellos — sin letra pequeña.

### Dónde viven tus datos

| Dato | Ubicación | Notas |
|------|----------|-------|
| **Claves de API** | `config/providers.toml` | Solo las lee Friday para llamar al proveedor que *tú* configuraste. Nunca se suben a ningún lugar. |
| **Memoria de conversación** | `memory_store/long_term.json` | JSON plano en tu disco — fácil de inspeccionar, respaldar o eliminar. |
| **Índice de vectores/embeddings** | `memory_store/vector_store.pkl`, `embeddings.pkl` | Índices de búsqueda locales para recuerdo semántico. |
| **Tokens OAuth de Google** | `memory_store/` | Se almacenan localmente después de que autorices Calendar/Gmail. |
| **Herramientas personalizadas** | `memory_store/custom_tools.json` | Las definiciones de herramientas que creas permanecen en tu máquina. |
| **Estado de Apagón** | `memory_store/blackout.json` | El estado del interruptor de privacidad se persiste localmente. |

### Qué sale de tu máquina

- **Solo las llamadas a tu proveedor de LLM configurado** (OpenRouter, OpenAI, Ollama, etc.) — y solo el contenido que le pides a Friday procesar. Si ejecutas Ollama localmente, **nada** relacionado con IA sale de tu máquina.
- **Los módulos de datos en vivo** (noticias, clima, acciones, cripto, CVE, etc.) consultan APIs públicas — solicitudes HTTP estándar, como cualquier panel.
- **Google Calendar/Gmail** solo se contactan cuando *tú* usas esas funciones, bajo tu propio consentimiento OAuth.

### Qué nunca sale de tu máquina

- **Análisis de pantalla y cámara** — tu pantalla se captura solo cuando *tú* lo pides, y solo los fotogramas que solicitas se envían a tu proveedor para análisis de visión. El monitor de cambios de pantalla en segundo plano se ejecuta por completo local (solo compara hashes de imágenes — nunca sube píxeles).
- **Voz y palabra de activación** — la detección de "Hey Friday" y la conversión de voz a texto se ejecutan **sin conexión en tu navegador**. No se sube ningún audio.
- **Control de computadora** — las acciones de clic, escritura y ventanas se ejecutan localmente. Las herramientas de control siempre requieren tu confirmación primero.

### 🚫 Modo Apagón

Activa un interruptor en Configuración y Friday pasa a ser por completo local: **todas las llamadas a herramientas de red quedan bloqueadas**, el proveedor se fuerza a **Ollama** y aparece un **sello PRIVADO** en el orbe. Cero tráfico de IA saliente. [Más información →](docs/v4-plan.md)

### Tus controles

- 🗑️ **Bórralo todo**: elimina el directorio `memory_store/` y tu `config/providers.toml`.
- 🔄 **Hazlo totalmente local**: cambia el proveedor a Ollama — el procesamiento de IA deja por completo de salir de tu máquina.
- 👀 **Audítalo**: la memoria es JSON plano. Ábrelo y ve exactamente lo que Friday recuerda sobre ti.
- 🚫 **Sin telemetría** — Friday no tiene analíticas, ni informes de errores, ni código de "llamar a casa".

```text
Friday/
├── core/                  # Lógica de negocio
│   ├── executor.py        #   Ejecución de llamadas a herramientas y streaming
│   ├── computer.py        #   Control del escritorio (aplicaciones, ventanas, entrada)
│   ├── rag.py             #   Segmentación local de documentos + rerankeo
│   ├── knowledge.py       #   Grafo de conocimiento de entidades/relaciones
│   ├── plugin_store.py    #   Registro de manifiestos del marketplace de plugins
│   ├── custom_tools.py    #   Creador de herramientas en lenguaje natural
│   ├── blackout.py        #   Modo de privacidad solo local
│   ├── hotkey.py          #   Atajo global a nivel de sistema
│   ├── autopilot.py       #   Descomposición de metas → pasos ejecutados
│   ├── memory/            #   Tres motores de memoria paralelos (TF-IDF, vector, embeddings)
│   ├── proactive.py       #   Monitores en segundo plano → alertas SSE
│   ├── automations.py     #   Motor de automatizaciones disparadas por cron
│   ├── vision.py          #   Captura y análisis de pantalla/cámara
│   └── auth/              #   OAuth de Google (Calendar, Gmail)
├── providers/             # Abstracción de proveedores LLM (conectables)
│   ├── registry.py        #   Autorregistro
│   ├── openai_compat.py   #   OpenRouter/OpenAI/cualquier API compatible con OpenAI
│   └── ollama.py          #   Modelos locales
├── plugins/               # Plugins de herramientas (se descubren automáticamente al iniciar)
│   ├── builtins/          #   Pantalla, correo, calendario, web, sistema, computadora…
│   ├── community/         #   Registro de plugins de la comunidad (marketplace)
│   └── manifest.json      #   Manifiestos de plugins
├── agent/                 # Núcleo del agente (metas, planificación, contexto de escritorio)
├── voice/                 # Entrada/salida de voz y palabra de activación (sin conexión, en el navegador)
├── browser/               # Automatización del navegador sin cabeza
├── desktop/               # Frontend (React 19 + Three.js + Vite + Tailwind)
│   ├── src/               #   Componentes, stores, hooks
│   ├── public/            #   Recursos e imágenes de funciones
│   └── api_server.py      #   Backend Quart (REST + SSE, puerto 8080)
├── config/                # providers.toml — tus claves de API y proveedores
├── memory_store/          # Memoria local (JSON + pickle) — se crea en tiempo de ejecución
├── docs/                  # Referencia de API y plan v4
└── tests/                 # 270+ pruebas pytest · desktop/src/test/ (107 vitest)
```

### ⚙️ Configuración

Toda la configuración vive en un solo archivo: `config/providers.toml` (cópialo de `config/providers.toml.example`).

| Ajuste | Valor predeterminado | Descripción |
|---------|---------|-------------|
| `[default] provider` | `"openrouter"` | Proveedor activo — `openrouter`, `openai`, `ollama` o cualquier API compatible con OpenAI |
| `[openrouter] api_key` | — | Tu clave de OpenRouter |
| `[openrouter] model` | `"openrouter/free"` | Modelo a usar (nivel gratuito por defecto) |
| `[openrouter] fallback_model` | `"meta-llama/llama-3.2-3b-instruct:free"` | Se usa cuando el modelo principal no está disponible |
| `[openai] base_url` | `"https://api.openai.com/v1"` | Cualquier endpoint compatible con OpenAI |
| `[ollama] base_url` | `"http://localhost:11434"` | Servidor local de Ollama |
| `temperature` | `0.7` | Aleatoriedad de la respuesta (por proveedor) |
| `max_tokens` | `4096` | Longitud máxima de respuesta (por proveedor) |
| `[embeddings] engine` | `"sentence"` | Motor de embeddings de memoria |

**Cambia de proveedor en tres pasos:**
1. Pega la clave de API en la sección del proveedor
2. Cambia `[default] provider` al nombre de ese proveedor
3. Reinicia el backend — listo

### Notas de arquitectura para contribuidores

- **Servidor API** — `desktop/api_server.py` (Quart, puerto 8080); el código a nivel de módulo se ejecuta al importar, así que las pruebas parchean `core.registry.discover_plugins` y `desktop.api_server._proactive` antes de importar
- **Agregar una herramienta** — crea una clase de plugin en `plugins/builtins/` que extienda `ToolPlugin`; se descubre automáticamente al iniciar
- **Agregar un plugin al marketplace** — añade un manifiesto a `plugins/manifest.json` y un paquete bajo `plugins/community/`
- **Agregar un endpoint** — define la ruta en `desktop/api_server.py`, usa `@require_auth` para endpoints autenticados
- **Memoria** — tres motores se ejecutan en paralelo: palabras clave (TF-IDF), vector (coseno), embeddings (sentence-transformers)
- **Convenciones** — PEP 8, longitud de línea 120, `async/await` para I/O, `asyncio.to_thread` para llamadas bloqueantes; commits convencionales (`feat:`, `fix:`, `test:`…)

## ❓ Preguntas Frecuentes

**¿Friday funciona sin conexión?**
Parcialmente. El frontend, la voz, la palabra de activación, la memoria, las automatizaciones y el control de computadora se ejecutan localmente. Las respuestas de LLM necesitan un proveedor de LLM — usa [Ollama](https://ollama.com) y todo funciona 100% sin conexión.

**¿Qué LLM puedo usar?**
Cualquier API compatible con OpenAI: OpenRouter (por defecto), OpenAI, Anthropic, Ollama o un `base_url` personalizado. Trae tu propia clave.

**¿Se envía mi pantalla a una empresa de IA?**
Solo cuando *tú* le pides a Friday analizar la pantalla, y solo al proveedor que *tú* configuraste. El monitor de cambios de pantalla en segundo plano compara hashes localmente y nunca sube píxeles. Las acciones de control de computadora siempre piden tu confirmación primero.

**¿Qué es el modo Apagón?**
Un interruptor que bloquea todas las herramientas de red, fuerza el proveedor de Ollama y muestra un sello PRIVADO en el orbe — privacidad total solo local. Perfecto para trabajos sensibles.

**¿Cómo hago que Friday sea totalmente local?**
Establece `[default] provider = "ollama"` en `config/providers.toml`, o simplemente activa el **modo Apagón** desde Configuración.

**¿Puedo personalizar la personalidad de Friday?**
Sí — tres personajes de voz (JARVIS, FRIDAY, Cortana) vienen integrados, cada uno con su propia voz TTS y prompt de sistema. Cambia cuando quieras mediante configuración o ⌘K.

**¿Puedo crear mis propias herramientas?**
Sí — el Creador de Herramientas Personalizadas convierte descripciones en lenguaje sencillo en herramientas funcionales y persistentes. Y el Marketplace de Plugins te permite instalar plugins de la comunidad con un clic.

**¿Qué son las automatizaciones?**
Acciones programadas con cron que creas en lenguaje natural ("crea una automatización para el resumen diario a las 8am"). El motor en segundo plano verifica cada 30s y envía los resultados vía SSE.

**¿Friday es gratuito?**
Sí — licencia MIT y gratuito para siempre. Solo pagas a tu proveedor de LLM si usas uno de pago (Ollama es gratuito).

**¿Cómo desinstalo / borro mis datos?**
Elimina `memory_store/` y `config/providers.toml`, luego detén los contenedores (`docker compose down`).
