# Support

## Where to get help

| Channel | Purpose |
|---------|---------|
| [GitHub Issues](https://github.com/alimaandev/Friday/issues) | Bug reports & feature requests |
| [GitHub Discussions](https://github.com/alimaandev/Friday/discussions) | Questions, ideas, show & tell |
| [Security](SECURITY.md) | Report security vulnerabilities |

### Before opening an issue

1. Search [existing issues](https://github.com/alimaandev/Friday/issues?q=is%3Aissue) — yours may already be reported
2. Search [discussions](https://github.com/alimaandev/Friday/discussions) — it may be a question, not a bug
3. Check the [README](README.md) — your answer may be in the docs
4. Run `docker compose up -d` with the latest `main` branch to confirm the issue persists
